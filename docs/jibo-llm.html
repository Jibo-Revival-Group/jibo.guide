jibo-llm

jibo-llm gives Jibo a brain again. It's a hotword-triggered conversational agent that connects your Jibo to any OpenAI-compatible LLM — GPT-4o, Claude, local models via Ollama or LM Studio, and more. Say "Hey Jibo" and have a real conversation, complete with expressive animations, vision, and web search.

ℹ️ How it works

When you say "Hey Jibo", jibo-llm:

  1. Listens for your speech via Jibo's on-board microphone
  2. Sends the transcript to an LLM with a system prompt and tool definitions
  3. Executes tool calls the LLM makes — speaking, animating, taking photos, searching the web
  4. Loops until the conversation ends, then resumes listening for the hotword

Conversations are fully interruptible — saying "Hey Jibo" mid-conversation aborts and starts fresh.

Prerequisites

  • Jibo in int-developer mode with SSH access
  • The Be skill (@be/be) must be running — jibo-llm communicates with Jibo through the ROM API that Be exposes. If Jibo is showing his eye, Be is running. See Skills Service Manager if you need to start it.
  • Local ASR service running on port 8088 — jibo-llm uses this for wake word detection and speech transcription
  • Node.js 18 or later on your computer
  • An OpenAI-compatible API endpoint (cloud or local)

Quick start

1. Clone & install

$ git clone https://github.com/Jibo-Revival-Group/jibo-llm.git
$ cd jibo-llm
$ npm install

2. Configure

$ cp .env.example .env

Edit .env:

JIBO_IP=192.168.1.217          # your Jibo's local IP

LLM_BASE_URL=https://api.openai.com/v1
LLM_API_TOKEN=sk-your-key-here
LLM_MODEL_ID=gpt-4o

BRAVE_API_KEY=your-key         # optional — enables web search

3. Run

$ npm start

You'll see:

[jibo-llm] Connecting to Jibo at 192.168.1.217…
[jibo-llm] Connected — session abc123
[jibo-llm] Ready — listening for "Hey Jibo"…

Say "Hey Jibo" and start talking.

LLM provider options

Any OpenAI-compatible endpoint works:

ProviderLLM_BASE_URLNotes
Ollama (local) http://localhost:11434/v1 Free, runs offline. Set LLM_API_TOKEN=ollama
LM Studio (local) http://localhost:1234/v1 Free, runs offline. Set LLM_API_TOKEN=lm-studio
OpenAI https://api.openai.com/v1 Requires API key
OpenRouter https://openrouter.ai/api/v1 Access many models via one key

What Jibo can do

The LLM can call these tools during a conversation. The system prompt includes a full ESML reference so the model uses Jibo's animation and sound system automatically:

CategoryTools
Speech say (with ESML animations), listen, end_conversation
Camera take_photo — image is sent to the LLM for visual understanding
Display show_text, show_image, show_eye
Movement look_at_angle — yaw ±180°, pitch ±30°
Audio set_volume (0.0 – 1.0)
Web web_search (Brave), fetch_url (reads web pages)

ESML — expressive speech

The LLM uses ESML (Embodied Speech Markup Language) tags inside say calls to trigger Jibo's animations in sync with speech: 

<!-- React happily -->
<anim cat='happy' nonBlocking='true' endNeutral='true'/> That's great news!

<!-- Laugh -->
<ssa cat='laughing' nonBlocking='true'/> That's hilarious!

<!-- Show a heart emoji -->
<anim cat='emoji' filter='!(hf), &(heart)' nonBlocking='true'/> I love that!

Agent loop

The agent runs a max of 25 turns per conversation. Key behaviors:

  • Speech chaining — multiple say calls queue and play sequentially without overlap
  • Tool ordering — say executes first, then actions (photo, search), then listen last
  • Interruptible — "Hey Jibo" mid-conversation aborts via AbortController and starts fresh
  • Image pruning — only the 2 most recent photos are kept in context to control token cost
  • Retry logic — automatic exponential backoff on 429 and 5xx errors
