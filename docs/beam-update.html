Update to BEam Skills

BEam is a collection of community system skills based on Jibo 1.9.2. It keeps the 2016-style experience while adding new skills, a 3D eye, local music, and a browser control panel. It is a community software update, not an official Jibo OTA.

ℹ️ Make sure you have SSH on your Jibo

Jibo needs the RCM recovery/mod path and SSH access before you update BEam. Keep a robot-specific eMMC or /var backup before changing skills.

⚠️ Check compatibility before applying

BEam changes the @be/be host and its bundled skill layout. Do not apply it to a robot whose base image or existing community stack does not match the release notes. The update script modifies the robot in place; read the current BEam README and keep recovery media available.

1. SSH into your Jibo

SSH into your Jibo using the following command: 

$ ssh root@[Jibo IP address]

The password is "jibo" (without the quotes).

2. Update the Jibo

Download the current script, inspect it, and then run it on the robot: 

$ curl -fL https://raw.githubusercontent.com/Jibo-Revival-Group/BEam/master/update-beam.sh -o /tmp/update-beam.sh
$ less /tmp/update-beam.sh
$ sh /tmp/update-beam.sh

This updates the BEam skill packs and normally restarts the Be skill. It may take several minutes and requires the robot to reach the configured OTA/package server. The script reads the robot's configured classic OTA endpoint; it is not automatically pointed at the OpenJibo server. Inspect /var/jibo/credentials.json and the current script before applying it. If you are self-hosting, see the OpenJibo/OTA notes and the OpenJibo server repository.

What BEam adds

  • System skill packs under @be/be/skills/; @be/be is the launchable host skill.
  • Recipe/Cooking, local-disk Jukebox, and Bad Apple; Doom is currently paused.
  • BEacon, a control panel at http://<jibo-ip>:8123 for the Jukebox, custom eye, loaded skills, and BEam updates.

OTA update flow

The OTA update flow is detailed in the upstream OpenJibo server repository if you want to inspect or recreate it. It follows the documented protocol and should be trivial to recreate for interested developers; implementation details remain subject to the current OpenJibo release notes.
