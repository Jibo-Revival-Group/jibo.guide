Update to Beam Skills

Beam Skills are a collection of skills that allow your Jibo to look like the 2016 design, while adding new features.

ℹ️ Make sure you have SSH on your Jibo

Jibo needs to be modded to access SSH, and you need to have SSH on your Jibo to update to Beam Skills.

1. SSH into your Jibo

SSH into your Jibo using the following command: 

$ ssh root@[Jibo IP address]

The password is "jibo" (without the quotes).

2. Update the Jibo

Update the Jibo using the following command: 

$ curl -k https://raw.githubusercontent.com/Jibo-Revival-Group/Beam/refs/heads/master/update-beam.sh | sh

This will update the Jibo to the latest version of Beam Skills, and automatically restart Be skill.
This process will take ~5 minutes to complete.
