Update to BEam Skills

BEam is a collection of community system skills based on Jibo 1.9.2. It keeps the 2016-style experience while adding new skills, a 3D eye, local music, and a browser control panel. It is a community software update, not an official Jibo Inc OTA.

ℹ️ Make sure you have SSH on your Jibo

Jibo needs the RCM recovery/mod path and SSH access before you update BEam. Keep a robot-specific eMMC or /var backup before changing skills.

⚠️ Check compatibility before applying

BEam changes the @be/be host and its bundled skill layout. Do not apply it to a robot whose base image or existing community stack does not match the release notes. The update script modifies the robot in place; read the current BEam README and keep recovery media available.

1. SSH into your Jibo

SSH into your Jibo using the following command: 

$ ssh root@[Jibo IP address]

The password is "jibo" (without the quotes).

2. Update and Configure the Jibo

Download the current script, inspect it, and then run it on the robot: 

$ curl -fsSL -k https://raw.githubusercontent.com/Jibo-Revival-Group/BEam/master/post-mod.sh -o /tmp/pm.sh
$ sh /tmp/pm.sh

This updates the BEam skill packs, configures the robot to reach the revival servers, and restarts the robot. It may take several minutes. If you are self-hosting, see the OpenJibo hosting guide for details on how to point your robot to your own server.

What BEam adds

  • System skill packs under @be/be/skills/; @be/be is the launchable host skill.
  • Recipe/Cooking, local-disk Jukebox, and Bad Apple; Doom is currently paused.
  • BEacon, a control panel at http://<jibo-ip>:8123 for the Jukebox, custom eye, and loaded skills.
  • Support for BEaker based OTA servers.

OTA update flow

The OTA update flow is detailed in the upstream BEaker repository if you want to inspect or recreate it. One warning, BEaker isn't intended to be self-hosted as it has environment specific settings that may mess up a standard self-hosted setup. It also makes receiving tech support more challenging, as robots may be running different software versions.
