Hosting OpenJibo Server

OpenJibo is a project that allows you to host your own Jibo server. This allows you to fully restore Jibo to his previous functionality.

ℹ️ You want Linux!!

Linux is the best operating system ever! I highly recommend using Linux to host the OpenJibo Server. It makes the entire process much easier. Overall, Linux is just better than other operating systems. I'll admit, this has just been my personal experience and opinion... but because of this the guide will be specifically for Linux. You can use Windows, but you may encounter issues.

1. Setting up the server

Recently a tool called EZJiboServer was created to make the process of hosting the OpenJibo Server much easier.

Run Installer Script

I encourage using the installer script to download the server. This will automatically download the server and set it (along with it's dependencies) up for you. 

$ cd ~ && curl -fsSL https://raw.githubusercontent.com/Jibo-Revival-Group/EZJiboServerGit/refs/heads/master/setup.sh | bash

2. Run the server

Once the server is downloaded and set up, you can run the server. 

$ cd ~/EZJiboServer && ./run.sh
