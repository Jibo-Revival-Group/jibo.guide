Hosting OpenJibo Server

OpenJibo is a project that allows you to host your own Jibo server. This allows you to fully restore Jibo to his previous functionality.

ℹ️ You want Linux!!

Linux is the best operating system ever! I highly recommend using Linux to host the OpenJibo Server. It makes the entire process much easier. Overall, Linux is just better than other operating systems. I'll admit, this has just been my personal experience and opinion... but because of this the guide will be specifically for Linux. You can use Windows, but you may encounter issues.

1. Downloading the OpenJibo Server

The first step for hosting the OpenJibo Server is to download the server from the OpenJibo GitHub.

Using Git CLI

I encourage using Git CLI to download the server. 

$ cd ~ && git clone https://github.com/Jibo-Revival-Group/JiboExperiments.git

This will download the server to your home directory. Once downloaded, you can navigate to the server directory. 

$ cd ~/JiboExperiments

2. Prepare your environment

Before you can build the OpenJibo Server, you need to prepare your environment. This is a pretty simple process, but it's important to follow the steps correctly.

  • .NET 10 (Install Guide)
  • PowerShell
  • openssl

If you're gonna be using a real Jibo, you'll also need some audio tools.

  • ffmpeg
  • whisper.cpp (Speech-to-text AI)

3. Configure the OpenJibo Server

The server has a .env file that you need to configure. This file is important for the server to work properly.

  • First, you need to copy the .env.example file to .env. 
    $ cd ~/JiboExperiments/OpenJibo && cp .env.example .env

Now, open the file in your preferred text editor. You now want to configure the variables. Here are the variables you should configure.

  • OPENJIBO_SEARCH_BACKEND This is where you choose the backend for Jibo Search. You can use Wolfram Alpha, ChatGPT, or Ollama. You also need to configure the API key for the backend you choose. They are seperated by a exclaimation mark (!). Here is an example of how it should look.
    OPENJIBO_SEARCH_BACKEND=ChatGPT!sk-proj-HRkbtWjtbJnrhwmOmrHrm....

  • OPENJIBO_SEARCH_FALLBACK This is where you choose the fallback backend for Jibo Search. You can use Wolfram Alpha, ChatGPT, or Ollama. It is the same as the OPENJIBO_SEARCH_BACKEND, but it is the fallback if the main backend fails.

  • OPENJIBO_STT_WHISPER_CLI_PATH (Only need this if you're using a real Jibo) This is where you put the path to your whisper.cpp binary. You can find the path by running which whisper-cli in your terminal.

  • OPENJIBO_STT_WHISPER_MODEL_PATH (Only need this if you're using a real Jibo) This is where you put the path to your whisper.cpp model. I use the ggml-base.en.bin model./
