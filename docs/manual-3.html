Route B — Step 3: Flash Back & First Boot

The modified /var partition is ready. This step writes it back to Jibo's eMMC, verifies the write, and boots Jibo for the first time in developer mode.

⚠️ Jibo must still be in RCM mode

If Jibo lost RCM mode (USB disconnected, etc.), you'll need to re-enter it before proceeding. See Step 1 — RCM Mode.

Part 5 — Convert Sector to Hex

ShofEL2's EMMC_WRITE command takes a hex address for the write offset. Convert your partition 5 start sector from decimal to hexadecimal: 

$ printf '0x%X\n' 8294434
0x7E9022

Or use any decimal-to-hex converter. If your Start sector was 8294434, the hex value is 0x7E9022.

ℹ️ Verify your value

If your fdisk output showed the same Start sector as the example (8294434), your hex is 0x7E9022. If your numbers differ, use printf '0x%X\n' YOUR_START_SECTOR to get your hex value.

Part 5 — Write the Modified Partition

Flash the modified var_partition.bin back to Jibo at the correct offset. Use your hex start address from the GPT, not the illustrative value unless it matches your dump: 

$ cd ~/JiboAutoMod/Shofel
$ sudo ./shofel2_t124 EMMC_WRITE 0x7E9022 var_partition.bin

ShofEL2 will print progress as it writes. This should complete in a few minutes (much faster than the initial dump).

Part 6 — Verify the Write

Read back the same region and compare MD5 hashes with your local file to confirm the write was successful: 

$ sudo ./shofel2_t124 EMMC_READ 0x7E9022 0xFA000 verify_var.bin
$ md5sum var_partition.bin verify_var.bin

You should see two identical hashes, like:

d41f3c29a8b1e7f0cc24... var_partition.bin
d41f3c29a8b1e7f0cc24... verify_var.bin
✅ Hashes match — you're done!

If both hashes are identical, the write was successful. If they differ, see Troubleshooting: Hash Mismatch.

Part 6 — Boot Jibo

  1. Unplug the USB cable from Jibo.
  2. Hold Jibo's power button until the red LED goes off completely, then release.
  3. Press the power button normally to boot Jibo.
  4. Instead of the normal startup animation, you'll see a large checkmark on Jibo's display. This confirms he booted into int-developer mode.
✅ Checkmark = success

The checkmark boot screen is your visual confirmation that the mode change worked.

SSH Into Jibo

With Jibo on your network and showing the checkmark, SSH in from your computer (use the IP address you noted earlier): 

$ ssh root@<your-jibo-ip>
# password: jibo

You should see a shell prompt like:

root@jibo:~#
🎉 You're in!

You now have full root shell access to your Jibo. The entire filesystem is accessible. Jibo's core OS, skills, and hardware interfaces are all available.

Head to SSH & Next Steps to install compatible community software such as BEam, or to connect the robot to OpenJibo.
