Re-Commander

Re-Commander is a local web-based control panel for Jibo. It connects directly to the robot's on-device ROM (Robot Operating Module) API over your LAN, giving you a browser UI to control head movement, trigger speech, listen, take photos, manage the display, and run a built-in LLM voice-AI loop — all with no cloud dependency.

Re-Commander running in a browser with Jibo connected.

Prerequisites

  • Jibo in int-developer mode with SSH access
  • Local ASR service running on port 8088 — required for the Listen button and wake word detection
  • Node.js 18 or later on your computer
  • Jibo and your computer on the same local network

Installation

$ git clone https://github.com/Jibo-Revival-Group/Re-Commander.git
$ cd Re-Commander
$ npm install

Configuration

Open server.js and set your robot's IP address:

const JIBO_HOST = '192.168.1.217';   // ← your Jibo's IP
const JIBO_PORT = 8160;              // leave as-is

Optionally create a .env file to configure the LLM integration: 

PORT=3000
LLM_ENDPOINT=http://localhost:11434/v1/chat/completions
LLM_MODEL=google/gemma-4-e4b
LLM_API_KEY=sk-...   # only needed for cloud providers
ℹ️ LLM endpoint

The LLM integration defaults to a local Ollama instance. Any OpenAI-compatible endpoint works — OpenAI, Anthropic via proxy, LM Studio, etc. If you skip the .env the Voice AI panel will use http://localhost:11434/v1/chat/completions by default.

Running

$ npm start

Open http://localhost:3000 in your browser. The status indicator in the top-left turns green once a session with the robot is established. If Jibo is unreachable the server retries automatically every 3 seconds.

What you can do

Head navigation

The arrow pad moves Jibo's head one step at a time, waiting for acknowledgment before sending the next command — no drift or command queuing. You can also click anywhere on the camera feed to make Jibo look at that point in the scene, with an optional continuous tracking mode.

Say & Listen

Type any text (plain or ESML markup) and press ▶ Say. Press 🎙 Listen to trigger Jibo's on-board ASR — the transcript appears below. Enable Auto-listen on hotword to have Re-Commander listen automatically every time "Hey Jibo" is detected.

Voice AI loop

Check LLM voice loop to enable a continuous hotword → listen → LLM → speak pipeline. Configure the endpoint, model, and system prompt directly in the UI or via .env. The built-in system prompt instructs the LLM to respond in ESML so Jibo speaks with matching animations.

Camera

Start a live MJPEG video stream from Jibo's right camera, take high-res stills, and browse a photo strip of everything captured this session. Photos are saved to photos/ in the project folder.

Display

Show Jibo's animated eye, play any of his built-in eye animations from a dropdown (blinks, expressions, emoji, transitions), or display custom text or an image URL on his screen.

Subscriptions & events

Toggle live streams for entity detection (person tracking), motion events, and head touch. A real-time event log on the right shows every message from the robot.
